how to run: 
open 3 terminals

1. run redis server:
   select wsl in the vscode terminal then type: 
    sudo apt install redis-server
    sudo service redis-server enable
    sudo service redis-server start
2. start backend:
   cd backend
   pip install -r requirements.txt     #this command is required only for the first time
   honcho start
3. start frontend
   cd frontend
   npm run dev
